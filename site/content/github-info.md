## Recent updates worth watching

- **Stacked pull requests are generally available (October 6, 2026):** Break a large change into smaller pull requests that are reviewed independently and merged together. Rebase stack now preserves approvals on unchanged code. [Read the Changelog](https://github.blog/changelog/2026-10-06-stacked-pull-requests-generally-available/).
- **GitHub Actions workflow lockfiles in public preview (October 14, 2026):** Keep tag and branch references in a workflow while running the exact commits you locked. Use the `gh actions-lock` CLI extension to create `.github/workflows/actions.lock`, and review dependencies before locking them. [Read the Changelog](https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview/).
